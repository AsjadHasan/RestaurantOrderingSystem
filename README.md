# RestaurantOrderingSystem
A restaurant's kitchen printer will need to print tickets for three types of orders - dine-in, takeout, and delivery. The waiter will enter the order live on the terminal, and the printing logic ifcannot have a separate branch for each type.
<br>

<br>
1. Class and Object
2. Inheritance
3. Constructor (__init__)
4. super() method
5. Method Overriding
6. Polymorphism
7. List and append()
8. While Loop
9. For Loop
10. User Input
11. split() and strip()
12. NotImplementedError
